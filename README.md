# 🛠️ Como Executar o Projeto

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/DalilaDeveloperMobile/Quiz_Biblico.git
```

## 2️⃣ Acesse a pasta do projeto

```bash
cd Quiz_Biblico
```

## 3️⃣ Instale as dependências

```bash
flutter pub get
```

## 4️⃣ Execute o aplicativo

```bash
flutter run
```
